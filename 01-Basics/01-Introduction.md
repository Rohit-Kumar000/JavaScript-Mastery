# JavaScript Introduction

## 1. What is JavaScript?

JavaScript is a **programming language** used to make websites **interactive and dynamic**.

For example, JavaScript can:

- Handle button clicks
- Change webpage content
- Change styles
- Validate forms
- Create interactive features
- Fetch data from APIs

Simple:

```text
HTML       → Structure
CSS        → Design
JavaScript → Behavior
```

---

## 2. Where Does JavaScript Run?

JavaScript commonly runs inside web browsers such as:

- Google Chrome
- Microsoft Edge
- Firefox
- Safari

JavaScript can also run outside the browser using environments such as **Node.js**.

---

## 3. How to Add JavaScript to HTML?

There are two common ways.

### Internal JavaScript

JavaScript is written inside the `<script>` tag.

```html
<script>
    console.log("Hello JavaScript");
</script>
```

### External JavaScript

JavaScript is written in a separate `.js` file.

```html
<script src="script.js"></script>
```

Example:

```text
index.html
script.js
```

---

## 4. Your First JavaScript Code

```javascript
console.log("Hello World");
```

`console.log()` is used to display information in the browser console.

You can open the browser console using:

```text
F12 → Console
```

or:

```text
Ctrl + Shift + J
```

---

## 5. JavaScript File Extension

JavaScript files use the `.js` extension.

Examples:

```text
script.js
main.js
app.js
```

---

## 6. HTML, CSS and JavaScript

Think of a webpage like this:

```text
HTML       → Creates the structure
CSS        → Designs the webpage
JavaScript → Adds functionality
```

Example:

```text
HTML       → Creates a button
CSS        → Designs the button
JavaScript → Makes the button work
```

---

## 7. Why Do We Use JavaScript?

JavaScript allows us to create interactive webpages.

For example:

```javascript
let name = "Rohit";

console.log("Hello " + name);
```

Output:

```text
Hello Rohit
```

Later, JavaScript can also be used to:

- Work with the DOM
- Handle events
- Work with APIs
- Create web applications
- Store data
- Build projects

---

## 8. Important Points

- JavaScript is a programming language.
- It is widely used for web development.
- JavaScript makes webpages interactive.
- `.js` is the JavaScript file extension.
- `console.log()` prints information to the console.
- `<script>` is used to connect JavaScript with HTML.
- External JavaScript is generally preferred for larger projects.
- JavaScript and Java are **different programming languages**.
